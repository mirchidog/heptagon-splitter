# heptagon-splitter
USB-C hub in the shape of a heptagon!
This is my first ever hardware project, and I based the design from the USB Hub tutorial by Outdatedcandy92. I wanted a geometric design that fit the upstream USB and the four downstream ones with a gap, and a heptagon (or septagon) was the best choice. I was able to learn the basics of schematics and PCB design, and now the manufacturing process. A rendering of the PCB:
